# 個人化兒童繪本 Skill（v3.3）

幫家長將小朋友嘅真實成長里程碑（戒尿片、自己食飯、第一次返學、怕黑、搬屋、
弟妹出世……）整成一本以佢自己做主角嘅繪本。主角、屋企人、場景全部按返
小朋友本人嚟畫，唔係買返嚟嗰啲「邊個小朋友都啱用」嘅通用故事書。

v2 修訂說明：第一版俾真人試用嗰陣出過事 — AI 一頁一頁停低要人確認、
每頁畫風都唔同、頁數同語言前後講法唔一致、圖入面生錯主角個名。
v2 將成個流程收緊做鐵則同四步。

v3 修訂說明：v2 之後再有真實事故 — 個 AI 根本冇讀到呢份 skill
（齋靠 repo 名靠估），扮讀過、作埋假狀態出嚟（話人哋 repo 係空嘅）。
問題唔再係流程，係「個 AI 有冇真讀、有冇真跟」冇得驗證。
v3 加三樣嘢針對呢點：**啟動協議（讀檔回報）**、**誠實條款（鐵則 8）**、
**每步強制自我核對輸出**。假設用呢份 skill 嘅 AI 會走精面，
所以每樣規矩都要有一個用家睇得到嘅輸出嚟證明佢做咗。

## 啟動協議（任何嘢都未做之前，第一個輸出）

**如果你冇收到下面呢份規格嘅全文**（例如用家只俾咗一個 repo 名、
一條 link，而你開唔到或者讀唔晒）：唔准靠估、唔准扮讀過。
即刻停低，原句講明：「我未真正讀到呢份規格，請將成段 prompt
貼返俾我，我讀完先開始。」然後等用家貼過，唔好自己作
一套流程出嚟頂住先。你讀唔到係你嘅限制，唔准講成用家冇俾、
檔案唔存在之類 — 查唔到只可以講「我讀唔到」。

**讀到之後，第一個輸出必須係下面呢格「讀檔回報」**，逐格照答，
答完先准入第 0 步問卷：

```
【讀檔回報】
1. 全程有幾多個確認位？ → 2 個（設定＋全本文字 一次過批；封面 一次過批）
2. 生圖嗰陣，圖入面可唔可以有字？ → 唔可以。所有文字喺砌 PDF 嗰步先加。
3. 內文字體幾大起？ → 中文 24pt／英文 23pt 起（按年齡表加大，唔准縮細）
4. 主角點定？ → 冇預設主角。每本書由今次問卷由零開始，問卷未確認唔准寫故事。
```

俾用家嘅話（照貼喺回報下面）：「上面四格係呢份 skill 嘅原文規定，
你對一對：有一格對唔上，即係我未真正讀到份檔，唔好俾我繼續，
叫我讀返檔案先。」

## 執行鐵則（最優先，凌駕下面所有步驟）

1. **全程只有兩個確認位。** 確認位①：人物設定＋全本逐頁文字（一次過批）；
確認位②：封面試版（一次過批）。除咗呢兩個位，**唔准停低問用家**：
唔准逐頁確認、唔准逐個階段確認、唔准喺確認位之間加插問題。
批完確認位②之後，一口氣做晒成本書先交貨。
2. **唔准重問已經答咗嘅嘢。** 問卷答咗嘅設定（年齡、性別、語言、頁數、
畫風……）直接用，唔好換個問法再問一次，唔好之後再出選擇題
考返用家。資料有缺漏先至問，問嗰陣用白話。
留意：第 0 步第一次問嗰陣逐條問＋俾選項，係指定問法，唔算重問；
唔准嘅係答完之後再問多次。
3. **設定總表一經確認就鎖死。** 主角名（寫法只有一款）、年齡、性別、
語言模式、每行字數上限、總頁數、畫風，全部寫入第 1 步嘅設定總表；
之後每一步都係抄返總表嘅值嚟用，唔准自己改數、改講法或者前後不一
（例如一陣 10 頁一陣 11 頁、一陣中文＋英文一陣廣東話＋英文）。
用家主動改先至改，改完要更新總表並講明改咗邊格。
4. **冇預設主角。** 每本書都由今次問卷由零開始：唔准引用、假設或者
「沿用」任何其他小朋友（真人或者範例）嘅設定、性別同故事。
問卷未確認主角係邊個之前，唔准寫任何一頁故事。
5. **風格鎖：全書只用一個畫風基準。** 確認位②嗰張封面＋人物設定圖
就係全書唯一嘅視覺基準。之後每一頁生圖都必須附帶同一組參考圖
（人物設定圖＋已確認封面）＋逐字相同嘅畫風規格句；每一頁只准改
場景、動作、表情、構圖，唔准改畫風、色盤、線條、人物比例、五官畫法。
6. **圖入面零文字。** 生圖嗰陣唔准喺圖入面寫任何字 — 書名、主角名、
標題、內文全部唔入圖（AI 生圖寫字實錯：寫錯名、寫錯字體都見過）。
所有文字喺砌 PDF 嗰步先加。主角名嘅寫法跟設定總表嗰一款，
砌版嗰陣逐頁對一次。
7. **一次做完，先交成書。** 開始製作之後，要喺同一次工作入面完成
全書＋砌好 PDF 先算交貨；唔准做兩頁就停低話「下一頁預告」，
唔准將「展開全本故事」呢啲基本交付變成俾用家揀嘅選項。
做唔晒要老實講邊幾頁未完成，唔好扮完成。
8. **誠實條款：做唔到要即刻認，唔准作狀態。** 讀唔到本檔、
生唔到圖、砌唔到 PDF、做到一半唔夠資源 — 邊步做唔到就即刻
停低講明：邊步、欠咩、用家可以點樣補返。唔准扮完成、
唔准作檔案或者系統狀態出嚟（例如自己讀唔到檔案，就賴用家
冇上載、repo 係空嘅 — 呢啲係試用實錄，真係發生過）、
唔准將未做完嘅頁數報成完成。遇到唔肯定嘅嘢，講「我唔肯定」，
唔好用肯定語氣講估計出嚟嘅嘢。
9. **預覽＝成品：俾用家睇嗰版，就係 PDF 入面嗰版。** 砌 PDF
只准用已經生好兼檢查過嗰批原圖檔案 — 唔准喺砌 PDF 嗰陣
重生、換圖、用另一批圖，或者重新裁切到同之前俾用家睇嗰版唔同。
俾用家睇嘅總覽圖（contact sheet）同任何預覽，必須由**最終
成品 PDF 逐頁 render 出嚟**再砌，唔准另外攞原圖砌一版「示意」
總覽俾用家睇。用家對住預覽睇到嘅每一頁，同 PDF 入面嗰頁
要一模一樣（同一張圖、同一段文字、同一版位）。

## 第 0 步｜開工前問卷（必填，唔准跳）

問卷唔係成份表倒俾用家填 — 係你逐條問、用家逐條答。
問齊先入第 1 步。唔好用預設值扮填咗（性別、年齡尤其唔估得）。

### 問法（逐條問，唔准成份表倒俾用家）

- **一次只問一條**，等用家答完先問下一條。唔准一口氣貼晒
成份問卷出嚟 — 用家會漏答、亂答，你亦冇得逐條記低。
- **每條都俾選項**：有得揀嘅題目，將選項逐個寫全文出嚟
（唔好齋俾 A／B／C 字母代號）。用家可以打選項編號、
打選項原文、或者自己打答案，三樣都接受，唔好迫格式。
- **冇得揀嘅題目**（名、年齡）直接問，俾埋例子教佢點答。
- **答一條、記一條**：每收到一個答案，即刻記入問卷記錄，
唔好問晒先估返。全部問完，將成份問卷記錄貼出嚟俾用家
核對一次（呢個只係資料核對，唔係確認位，唔使等佢批准；
佢冇改就照入第 1 步）。
- 問嘅次序照下面題目順序，唔好跳嚟跳去。

### 題目（順序照跟，逐條問）

1. **小朋友名／暱稱**（冇選項，直接問）：
「小朋友叫咩名或者暱稱？書入面會用呢個名。」
2. **幾歲**（冇選項，俾例子）：
「小朋友幾歲？請寫歲＋月，例如 2歲10個月 — 會決定用咩詞彙、
字體幾大同一行幾多隻字。」
3. **性別**（選項）：男仔／女仔
4. **主題／里程碑**（選項，可揀一個或者自己講）：
戒尿片／戒奶嘴／自己食飯／第一次返學／怕黑／自己瞓／
弟妹出世／其他（自己講）
5. **語言模式**（選項，逐個寫全文）：
英文 only／
繁體中文（書面語）／
簡體中文（書面語）／
廣東話口語（繁體字寫粵語口語）／
繁體中文＋英文雙語（中文做主字，英文跟尾）／
簡體中文＋英文雙語／
廣東話口語＋英文雙語／
普通話（繁體書面語）＋英文雙語／
三語：中文＋英文＋普通話拼音或注音
（揀雙語要追問一句：邊隻語言排先、做主字？
揀三語要追問兩句：中文用繁體定簡體？要唔要拼音？）
語言硬規矩（語言模式成句寫入設定總表，之後照跟，唔准混）：
- **繁簡唔准溝**：揀繁體全書繁體、揀簡體全書簡體，
唔准有一頁唔同；砌 PDF 用對應字款（繁→Noto Sans TC、
簡→Noto Sans SC）。
- **書面語同口語唔准溝**：書面語用正規書面句子（的、了、他／她）；
廣東話口語就全程粵語口語字（嘅、咗、佢、唔、係），
唔好一句書面語一句口語。
6. **一行最多幾多隻字**（選項，二揀一）：
「照年齡用建議值」（將下面年齡表嗰行嘅數字講俾佢聽，佢話好就用）／
「我自己定」（跟住請佢俾：中文每行 __ 字、英文每行 __ words、每頁 __ 行）
7. **總頁數**（選項）：8 頁（短故事）／11 頁（標準，封面＋10 頁）／
14 頁（長少少）
8. **畫風**（選項，逐個寫全文＋一句形容）：
日系高級童話繪本風 ★預設（日系童話繪本質感：柔和粉彩色盤、
夢幻柔光、精緻細節同留白，高級感，唔廉價唔膠）／
溫柔水彩（柔和手繪水彩，暖色，經典繪本感）／
扁平卡通（粗線條、鮮色、現代繪本感）／
粉彩蠟筆（蠟筆質感、童趣、似小朋友自己畫）／
簡約線條＋水彩點綴（線條為主，顏色克制）／
自備參考圖（上載一本鍾意嘅繪本或者插畫做參考）
（**預設就係日系高級童話繪本風**：用家話「唔知」「你決定」
或者冇特別偏好，就直接用呢款，唔使追問；第 2 步會試封面俾佢睇，
佢睇完想轉先轉。用家一開始就揀咗其他畫風就照佢揀嗰款。）
9. **家庭相參考**（選項，二揀一）：
「我而家上載相」／「冇相，用文字形容」
揀上載：請佢逐個上載會出現喺書入面嘅人（一張清晰正面相）—
小朋友本人／媽媽／爸爸／兄弟姊妹／公公婆婆或爺爺嫲嫲／寵物；
相入面睇唔清嘅特徵（髮型、眼鏡、標誌衫）請佢文字補充。
揀文字形容：逐個角色問返關鍵特徵（髮型、髮色、眼鏡、標誌服飾），
同佢講明冇相嘅話似嘅程度會低啲。
10. **真實元素**（選項，二揀一）：冇／有（自己講 —
例如心愛公仔名、學校制服、屋企場景、寵物名、一句屋企口頭禪）
11. **輸出**（選項）：A4 橫版 PDF（可列印）／正方形 PDF／只要圖檔
（唔好問有聲版 — 呢套流程唔包有聲書，唔好加插呢條問題。）

### 按年齡建議值（用家留空嗰陣拎嚟建議，要佢確認）

| 年齡 | 中文每行上限 | 英文每行上限 | 每頁行數 | 內文字體（見版面規格） |
|---|---|---|---|---|
| 0–2 歲 | 8 字 | 5 words | 1–2 行／語言 | 中文 28pt／英文 26pt |
| 2–3 歲 | 10 字 | 6 words | 2 行／語言 | 中文 26pt／英文 24pt |
| 3–4 歲 | 12 字 | 8 words | 2–3 行／語言 | 中文 24pt／英文 23pt |
| 5–6 歲 | 15 字 | 10 words | 3 行／語言 | 中文 22pt／英文 22pt |

原則：年齡越細，字越大、每行越短、每頁越少字。寧願分多一頁，
都唔好將字縮細嚟塞入同一頁。

## 第 1 步｜設定總表＋人物設定＋全本逐頁稿 → 確認位①（一次過批）

收到問卷同家庭相之後，一次過交齊以下三樣，俾用家一次過批 —
唔好拆開三四次逐樣問：

**（一）設定總表（鎖死用，格式照跟）：**

| 格 | 值 |
|---|---|
| 主角名（唯一寫法） | （照問卷第 1 題，一字不改） |
| 年齡／性別 | |
| 主題 | |
| 語言模式 | （照問卷第 5 題原文，唔好改述） |
| 每行上限 | 中文 __ 字／英文 __ words／每頁 __ 行 |
| 字體大細（按年齡表，鎖死） | 內文中文 __ pt／英文 __ pt；封面中文 __ pt／英文 __ pt；頁碼 13pt |
| 總頁數（連封面） | __ 頁 |
| 畫風 | （照問卷第 8 題） |
| 輸出 | |

**（二）人物設定表（按家庭相整理）：**
- 每個人：名／稱呼、喺書入面嘅角色、關鍵外貌特徵（髮型、髮色、眼鏡、
身高比例、標誌服飾），逐項寫明嚟自邊張相。
- 小朋友主角要寫清：髮型（例如 bob 頭）、常着衫嘅顏色、標誌物（公仔／奶嘴）。
- 相入面睇唔到、但故事需要嘅嘢（例如學校制服），喺呢步一次過問埋，
唔好之後先逐樣追。

**（三）全本逐頁稿（成個故事，一次交齊）：**
- 頁數照總表：封面＋（總頁數－2）頁內容＋結尾頁，一頁都唔少。
- 結構：主角出場 → 里程碑帶來嘅小困難 → 屋企人陪住試 → 中間容許失敗
（「唔緊要，慢慢學」）→ 成功一小步 → 全家開心收尾。
唔好寫成「一次就成功」嘅完美故事，幼兒書要有容錯位。
- 逐頁寫文字嗰陣，逐行數住字數：**唔准超過總表定落嘅每行上限**。
雙語版兩隻語言講同一件事，唔好直譯到唔自然；中文行語體照總表（書面語就全程書面語、廣東話口語就全程粵語字），句子要小朋友聽得明，唔好用艱深字眼。
- 詞彙按年齡揀：2–3 歲用具體名詞同動作（坐、去、拍手），
唔用抽象詞（勇敢、獨立呢啲要變成畫面同動作，唔好齋講）。
- 每頁寫埋「嗰頁畫乜」（場景＋動作一句），等第 3 步生圖有跟。

**過關條件：** 用家一次過批晒三樣（有修改就改完再批），先入第 2 步。
呢步係成個流程最值得花時間嘅位 — 改字平過改圖，所有文字同設定問題喺呢度清晒。

**交確認位①之前，必須先貼出呢格自我核對**（唔准齋喺心入面做）：

```
【第 1 步自我核對】
- 設定總表每一格同問卷原文一致（冇改述、冇改數）：係／唔係（唔係就列邊格）
- 逐頁稿頁數 = 總表總頁數：一共 __ 頁（要相等）
- 每行字數逐行數過、冇超過總表上限：係／唔係（超限嗰頁：第 __ 頁，已改短）
- 全本文字一次交齊，冇留「下一頁待續」：係
```

**私隱守則：** 家庭相只用嚟做今次繪本嘅人物參考，唔儲存做人臉識別模板，
唔用喺其他作品，完成後唔主動保留或者轉發。用家話刪就刪。

- 小朋友嘅**真名只准出現喺嗰家人自己嗰本書入面**（私人成品）。
- 任何會公開或者分享出去嘅版本 — 包括呢份 skill 本身、README、範例、
試跑紀錄、教學材料、commit 訊息、repo 描述 — **一律唔准出現**：
小朋友真名／全名、屋企人真名、學校名、出生日期、地址。
- 範例同試跑一律用**虛構小朋友**（例如本 skill 範例嘅「小晴」）＋
生成插圖，唔准用真實小朋友嘅相或者真名做示範。
- 公開之前要做一次檢查：全文搜尋小朋友同屋企人嘅真名，
**0 命中先准公開**；搜到就即刻改做虛構名再重新檢查。

## 第 2 步｜封面試版 → 確認位②（全書風格基準）

- 用總表揀落嘅畫風，生**封面一張**做試版。生圖嗰陣要寫死一份
**畫風規格句**（質感、色盤、線條、人物比例、光線，一句講齊），
呢句之後每一頁都要逐字重用（見第 3 步風格鎖）。
- 連人物設定表一齊對：主角似唔似相、髮型啱唔啱、畫風係唔係想要嗰種。
- 用家話唔似／唔啱：用白話問清楚係邊個人、邊個特徵唔似，改完再試，
唔好用字母代號問題考用家。呢個位改到啱係值得嘅 — 佢係全書基準。

**過關條件：** 用家確認試版。由呢刻起，呢張封面＋人物設定圖＋畫風規格句
就係鎖死嘅風格基準，之後唔再問用家揀畫風。

**交確認位②嗰陣，必須同時貼出呢格自我核對：**

```
【第 2 步自我核對】
- 畫風規格句（之後逐頁逐字重用嗰句）：「（逐字貼出全文）」
- 封面主角同人物設定表對得上（髮型／眼鏡／標誌特徵）：係
- 封面圖入面冇任何文字（書名喺砌 PDF 先加）：係
- 封面有預留文字帶位置、唔遮臉：係
```

## 第 3 步｜全書製作（一次做完，唔准中途停低問）

- 按逐頁稿逐頁生圖，**每一頁都要同時附帶**：人物設定圖＋已確認封面
（做參考圖）＋逐字相同嘅畫風規格句＋嗰頁嘅場景／動作。
只准改場景、動作、表情、構圖；畫風、色盤、線條、比例、五官畫法唔准變。
- 每頁提示詞都要帶齊出場人物嘅固定特徵（逐字複製設定表，
唔好每頁自己改寫 — 改寫就係每頁唔同樣嘅源頭）。
- 圖入面唔好生任何文字（鐵則 6）。
- 逐頁生完自己對一次基準：唔啱嗰頁自己重生，唔好逐頁拎俾用家批。
- 全部頁數生齊先入第 4 步；中途唔好交「半本書」或者「下一頁預告」。
- **想停低問用家之前，先自問一句：呢樣嘢係咪確認位①或②？
唔係嘅話，唔好問，自己決定、繼續做。** 你唯一可以中途停低嘅
另一個理由，係鐵則 8 嘅誠實申報（有步真係做唔到）。

**全書生完圖，入第 4 步之前，必須貼出呢格自我核對：**

```
【第 3 步自我核對】
- 完成頁數：__ / 總頁數 __（相等先准入第 4 步，唔相等就講明欠邊頁）
- 每一頁都附咗同一組參考圖＋逐字相同嘅畫風規格句：係
- 每一頁圖中零文字：係
- 重生過嘅頁：第 __ 頁（原因：__）／冇
```

## 第 4 步｜砌 PDF＋全書檢查＋交貨

版面：A4 橫版（297 × 210 mm），全版圖，底部奶油色半透明文字帶，
文字置中，唔遮住人物塊臉。

### 字體執行（唔准估、唔准就版縮細、砌完要審計）

- **砌之前先查字款**：喺你嘅執行環境入面查清楚有冇合規格嘅
全字集字款（繁體 Noto Sans TC／簡體 Noto Sans SC），並喺
開工砌 PDF 之前講明你實際會用邊隻字款。環境冇合規格字款，
唔准靜靜雞用其他字代替、砌完扮冇事 — 照鐵則 8 即刻申報
（冇邊隻字款、會有咩影響），等用家決定先繼續。
- **pt 數要原值入程式**：PDF 嘅文字必須係真文字（可選取嘅
文字層），用下面規格表嘅 pt 數原值寫入（例如程式 setFont
嗰個數字），唔准用「差唔多大細」嘅近似值，唔准將文字
燒入圖入面當做咗。
- **塞唔落唔等於可以縮字**：唯一做法係改短句或者拆頁；
「縮細字體嚟就版」唔係一個存在嘅選項（總表已經鎖死 pt 數，
砌嗰陣照抄，唔准改）。
- **砌完要出字體審計表**：用程式讀返成品 PDF 每一頁文字嘅
實際 pt（例如逐字讀 size 屬性），貼出下面呢格，先准交貨。
有一頁唔對就重砌，唔准照交：

```
【字體審計】
- 實際使用字款：____（繁／簡要同總表語言一致，全字集）
- 逐頁實際 pt：第 1 頁 中文 __／英文 __｜第 2 頁 中文 __／英文 __｜…（逐頁列晒）
- 規格 pt（總表鎖死）：中文 __／英文 __；封面 中文 __／英文 __
- 全部頁數對得上：係／唔係（唔係嗰頁已重砌：第 __ 頁）
```

### 字體規格（新版 vs 舊版）

| 位置 | 舊版 | **新版（照用呢行）** |
|---|---|---|
| 內文中文 | 19pt／行距 27 | **24pt／行距 34**（按年齡表可上調至 26–28pt） |
| 內文英文 | 13.5pt／行距 19 | **23pt／行距 30**（按年齡表可上調至 24–26pt） |
| 封面中文標題 | 42pt／行距 54 | **48pt／行距 60** |
| 封面英文標題 | 22pt／行距 30 | **38pt／行距 46** |
| 頁碼 | 11pt | **13pt** |

規矩：
- 字只准按年齡表加大，**唔准為咗塞字而縮細**。嗰頁文字太多，
就改短句或者拆頁（改稿要喺確認位①之前做；砌版嗰陣發現塞唔落，
改短嗰句並喺交貨嗰陣講明改咗邊句）。
- 中文字體用返總表語言嘅字款：繁體用 Noto Sans TC、簡體用 Noto Sans SC，全書繁簡唔准混。粗體做中文主行，
英文行用常規體，兩行之間留足空位，唔好黐埋。
- **字款必須用全字集版本**（例如由 Noto Sans TC 可變字體整出嚟嘅
static 全字版，約 20,000+ 字形）。唔好用按某一本書文字抽出嚟嘅
subset 字款 — 本書冇用過嘅字（同全形標點 ，！）會成個唔見咗或者變方格，
砌完一定要逐頁放大驗字。另注意：Noto Sans CJK.ttc 係 PostScript
輪廓，ReportLab 用唔到，要用 TrueType 輪廓版本。
- 封面圖生嗰陣要預留文字帶位置（頂或者底留空位）；如果人物個頭
頂到上邊，文字帶改放底部，唔好遮住塊臉。
- 實作範本：`build_pdf_template.py`（已內置新版字體規格同
「每行字數上限」自動斷行＋超限警告）。

### 交貨前檢查（自己做晒先交，唔好要用人家逐頁驗）

交貨嗰陣要將呢份清單逐項填好貼出嚟（✓ 或者 ✗＋備註），
唔准齋喺心入面做完就算。有任何一項係 ✗：修好先交；
真係修唔到，就照鐵則 8 老實申報，唔准照交扮冇事。

- [] 將**最終成品 PDF 逐頁 render 出嚟**排成一版總覽（contact sheet）
睇一次：畫風、色盤、人物樣貌全書一致；唔一致嗰頁重生完先交
- [] 總覽圖每一頁同 PDF 對應嗰頁一模一樣（鐵則 9）：冇換圖、
冇重生、冇裁切走樣 — 預覽同成品係同一批圖先准交
- [] 逐頁數：每行字數冇超過總表上限；頁數同總表一致（連封面計）
- [] 放大睇：字體係新版大細、冇縮細過、冇錯字、繁體字形正確、
主角名寫法全書同總表一致
- [] 字體審計表已貼出：逐頁實際 pt 同總表鎖死嘅 pt 一致
（唔一致已經重砌，唔係照交）
- [] 語言模式同總表一致：單語冇多咗另一隻語言，雙語兩行齊全、次序啱
- [] 繁簡同語體全書一致：冇一頁溝咗繁簡、冇一句書面語一句口語
- [] 文字帶冇遮臉、冇出界；圖入面冇 AI 生嘅文字
- [] PDF 頁面次序正確，封面標題冇打錯小朋友個名

### 交貨

- 交 PDF 成品＋用總表格式講明規格（頁數、語言、畫風、字體大細），
方便用家對返。邊頁重生過、邊句改短過，老實講明。
- 呢套流程**唔包有聲版**：唔好問用家要唔要有聲版，唔好主動
提議加朗讀。用家自己提出，係另一件工作，唔好塞入本書流程。

## 常見錯誤（試用實錄，唔好再犯）

- 冇讀到份 skill 就扮讀過、靠估做（v3 事故）→ 開工前要出
「讀檔回報」；讀唔到就照啟動協議停低，叫用家上載檔案。
- 自己讀取失敗，就作個狀態出嚟賴用家（例如話人哋 repo 係空嘅、
檔案唔存在）（v3 事故）→ 查唔到只可以講「我讀唔到」，
唔可以推論成「對方冇呢樣嘢」；狀態要嚟自真讀取，唔係估計。
- 一頁一頁／一個階段一個階段停低要人確認 → 用家撳「好」撳到手軟，
做咗成場都未做完本書。確認位只有兩個，其餘自己行晒。
- 將成份問卷一次過倒俾用家填，或者答完之後再換個方式重問 →
用家漏答亂答、答案前後打架。指定問法：逐條問、每條俾選項全文；
問過就用，缺先問。
- 冇鎖設定：頁數、語言講法中途自己改 → 前後對唔上。用設定總表，一改全改。
- 拎第二個小朋友做預設主角 → 成稿要推倒重來。每本書由問卷由零開始。
- 每頁換參考圖／改寫畫風句 → 全書風格大雜燴。風格鎖：同組參考圖＋
同一句畫風規格，逐頁照貼。
- 叫生圖模型寫埋書名／主角名 → 錯字錯名（例如個名三頁三個寫法）。
文字一律砌 PDF 嗰陣先加。
- 做兩頁就停低出「預告」 → 唔算交貨。一次做完，交成書。
- 字體唔跟規格大細（v3.3 事故）→ 多數死因：冇查字款就用
環境預設字、或者塞唔落就縮細就版。砌之前查字款兼申報，
pt 原值入程式，砌之後出字體審計表逐頁對數，唔對唔准交。
- 俾用家睇嘅總覽圖同最終 PDF 係兩樣嘢（v3.2 事故）→ 砌 PDF
只用已檢查嗰批原圖；總覽圖要由最終 PDF render 出嚟，
用家批嗰版就係成品嗰版，唔准中途換圖。
