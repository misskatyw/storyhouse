# picture-book-skill — 個人化兒童繪本

一個俾 AI 助手用嘅 skill：幫家長將小朋友嘅成長里程碑整成一本
以小朋友自己做主角嘅個人化繪本（PDF）。

## 特色

- **防扮讀設計**（v3 重點）：AI 開工前要先出「讀檔回報」，逐格答返四條得份檔先有嘅規定 — 朋友 10 秒就驗到佢係咪真讀過；做唔到要即刻申報，唔准作狀態；每步過關前要貼自我核對，冇得走精面
- **只有兩個確認位**（v2 重點）：一次過批「設定＋全本文字」、一次過批「封面」，之後 AI 一口氣做晒成本書，唔逐頁停低問；設定總表鎖死，唔會頁數／語言前後唔一致；全書共用一個風格基準，唔會每頁唔同畫風；生圖零文字，唔會寫錯主角名
- **問卷逐條問、每條有選項**：唔使對住成份表自己填 — AI 一條一條問，
有得揀嘅題目俾齊選項，揀就得；問清小朋友幾歲、男仔定女仔、
單語／雙語／三語、一行最多幾多隻字、總共幾多頁，唔估、唔跳步
- **揀畫風**：預設係**日系高級童話繪本風**（柔和粉彩、夢幻柔光、精緻高級感），
唔揀就用呢款；亦可揀溫柔水彩／扁平卡通／粉彩蠟筆／簡約線條，或者自備參考圖；
先試一頁封面，確認先批量生圖
- **家庭相做參考**：用家長上載嘅家庭相整理人物設定表（髮型、眼鏡、標誌服飾），
畫出嚟嘅主角同屋企人先會似返本人
- **加大字體版面**：內文中文 24pt／英文 23pt 起（按年齡最高 28／26pt），
細過嘅小朋友都睇得清；文字太多就改短句，唔縮字
- **每行字數硬上限**：按年齡定每行字數，逐行檢查，幼兒唔使追長句

## 點用（重要，唔好齋俾 repo 名）

⚠️ **齋打 repo 名或者條 link 俾 AI，佢係載入唔到呢份 skill 嘅。**
一般聊天 AI（例如 ChatGPT）冇「輸入 repo 名就自動安裝 skill」呢個功能 —
你唔將檔案本身俾佢，佢只會靠估亂做，仲會扮到好似讀過咁。

正確做法（二揀一）：
- **ChatGPT／其他聊天 AI**：喺呢個 repo 撳入 `SKILL.md` → 右上角下載掣
  下載個檔 → 開新對話，將 **SKILL.md 個檔案上載**入對話，再貼下面
  嗰段「啟動咒語」。見到佢出返「讀檔回報」而且四格都啱，先算載入成功；
  淨係出問卷都未夠 — 冇回報或者回報錯格，即係佢冇真讀到，叫佢讀返個檔。
- **Claude／識用 skills 嘅助手**：將 `SKILL.md` 放入佢嘅 skills 目錄，
  或者成個檔案貼入對話，一樣由問卷開始。

### 啟動咒語（copy 呢段，連 SKILL.md 一齐俾你個 AI）

```
跟住我上載嘅 SKILL.md 做，唔好靠估。第一個輸出要係份檔要求嘅
「讀檔回報」，四格逐格答；答唔出或者答錯，你就老實講你未讀到，
叫我上載返個檔案，唔好扮讀過。之後由問卷開始，全程只有兩個
確認位，其餘做晒先交；邊步做唔到即刻講明，唔准作狀態出嚟。
```

跟住落嚟：

1. 將 `SKILL.md` 交俾你嘅 AI 助手（或者放入佢嘅 skills 目錄）。
2. 同助手講「幫我整本繪本」，佢會先俾一份你填。
3. 填好問卷、上載家庭相，確認人物設定表同逐頁文字稿，再確認封面試版。
4. 助手會生圖並用 `build_pdf_template.py` 砌成 A4 橫版 PDF。

## 檔案

- `SKILL.md` — 完整流程：問卷 → 人物設定 → 故事 → 試版 → 生圖 → 砌 PDF → 檢查
- `build_pdf_template.py` — 砌 PDF 範本（ReportLab），已內置加大字體規格
同每行字數超限警告；需要 Noto Sans TC 字款（Regular／Bold）放喺同目錄
- `PROMPT.md` — Prompt 版：同一套規矩寫成成段文字，貼入任何 AI 對話就用得（v3.1，包埋繁／簡同書面語／口語）
- `BUILD_BRIEF.md` — 網頁製作規格：將套 skill 起成網頁工具嗰陣俾製作方跟嘅 brief
- `CHANGELOG.md` — 版本修訂紀錄（v2、v3 都係真實試用事故嘅覆盤修訂）
- `examples/trial-run.md` — 一次完整試跑示範（問卷填寫 → 設定表 → 逐頁稿）
- `examples/images-trial/` — 試跑示範《小晴自己刷牙仔》嘅 4 張水彩頁圖

## 私隱

家庭相只用嚟做該次繪本嘅人物外貌參考，唔應用嚟建立人臉識別模板，
亦唔應該用喺其他作品。
